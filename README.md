# games

生成AIで生成したブラウザだけで動く軽量日本語ゲームの詰め合わせです。
多くは軽く動作確認をしただけのプロトタイプなので、バグや荒削りな部分があるかもしれません。

## ゲーム一覧

ブラウザから（https://shinkai-dev.github.io/games/）にアクセスし、下記のゲームを直接選んで遊ぶか、各フォルダの `index.html` を開いてプレイできます。

## ローカルでの動かし方

ビルド手順やサーバー、外部ライブラリのインストールは不要です。

1. このリポジトリをクローンまたはダウンロードします
2. 遊びたいゲームのフォルダにある `index.html` をブラウザで開きます。
