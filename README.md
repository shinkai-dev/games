# games

A vault of lightweight, browser-only games generated with AI.

Most of the games here are quick prototypes that have only been lightly tested—some might have bugs or rough edges, so please enjoy them as casual experiments!

## Games

Play directly in your browser or open each folder's `index.html` locally:

- **[Super Hopper](./super-hopper/)** — A 2D side-scrolling platformer *(inspired by Super Mario Bros.)*.
- **[Block Stacker](./block-stacker/)** — A classic falling-block puzzle game *(inspired by Tetris)*.
- **[Bomb Maze](./bomb-maze/)** — A grid-based bomb-placing action game *(inspired by Bomberman)*.
- **[Gate Rush](./gate-rush/)** — A lane-moving auto-shooter runner *(inspired by mobile ad games like Last War)*.
- **[Mako7](./mako7/)** — A cyberpunk/fantasy RPG *(inspired by Final Fantasy VII)*.
- **[Pocket Battler](./pocket-battler/)** — A monster-collecting & turn-based battle RPG *(inspired by Pokémon)*.
- **[Pocket Battler 2](./pocket-battler2/)** — A modernized roguelite sequel to Pocket Battler *(inspired by Pokémon)*.
