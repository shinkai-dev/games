操作とシステム

目的

3つの戦域を突破し、炉心の守護機「スコルピア」を撃破して魔晄炉を強制停止せよ。全滅すると作戦失敗。戦闘はリアルタイムで進むATB(アクティブタイムバトル)。

基本操作

↑ ↓ / 1-4コマンド選択 Enter / Z決定 Esc / X戻る・キャンセル ← → / Tabターゲット切替 クリックコマンド選択 / 敵・味方を直接タップで対象決定

ATBゲージとWAIT

ATBが満タンになったキャラから行動できます。WAITモードではコマンド入力中に時間が停止(初心者推奨)。ACTIVEでは入力中も敵が動きます。バトルスピードは1〜5で調整可能。

リミット技

ダメージを受けるとLIMITゲージが蓄積。満タンになると「たたかう」が必殺のリミット技に変化します。演出中は時間が歪みます。

敵のギミック

  • 尾部展開(スコルピア)：尻尾を掲げた間は攻撃すると尾部レーザーのカウンターを誘発。「まもる」や回復・補助に徹するのが定石。
  • チャージ砲：グリフの全体砲撃、スコルピアの魔晄砲は予告あり。「まもる」(被弾半減)とアイアンウォールで耐え切れ。

防御と補助

「まもる」は次の行動まで被ダメージ半減。バリアは25秒間-40%。ヘイストはATB加速。パイルショットは敵のATBを削ります。

作戦評価

クリアタイム・戦闘不能回数・アイテム使用数・リミット使用数で S / A / B / C を判定。ハードボーナスあり。ベスト記録は端末に保存されます。
